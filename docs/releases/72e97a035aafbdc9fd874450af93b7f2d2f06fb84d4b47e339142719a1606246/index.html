実装ルールと適用範囲

初回取得した本文は自動承認しません。税務レビューで承認された公式本文指紋と、毎回の取得内容を照合します。変更疑い・取得失敗・期限切れ・未対応年度では、その資料を必要とする機能の金額表示・印刷を停止します。基本計算、教育、認定、繰越、予測換算の承認は別です。

最新確認の実現方法と限界

公開版は専用照合サービス、ローカル版はNode.jsサーバが、固定した公式URLのみを毎回取得します。APIに給与・社名・年度・任意URLは送信しません。公式取得確認は最長15分、機能レビューの期限が先に来ればその時点で停止します。端末時計の巻戻しも無効とし、画面復帰や再計算時に取得し直します。

本文やPDFの変更は法改正以外でも起こるため再レビューが必要です。指紋一致も未知の新法令・別ページでの告知まで保証しません。レビューの有効期限と対象範囲を別途管理します。静的ホスティングだけでは、この毎回の公式確認APIを提供できません。

公開版はGitHub Pagesと公式資料の照合専用サービスを利用します。給与・CSVは送信しません。照合サービスが停止した場合や公式資料に接続できない場合は、該当する計算を停止します。
