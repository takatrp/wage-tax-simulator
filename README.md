# 賃上げ促進税制シミュレーター

松本さん向けの法人用ローカルWebツールです。給与・CSV・案件名はブラウザ内で処理します。**中小基本計算（2025・2026年度開始）と年間見込だけを、計画用の限定範囲として有効化します。申告用監査保証ではありません。** 通常の内国法人・非受託・非通算・特殊法人なし、認定なし、既存繰越0円、旧年度の教育加算なしが必要です。他の年度・枠・加算・繰越利用は未承認で停止します。詳細は「限定確認の範囲.txt」とactivation-verification.jsonを参照。レビュー更新期限は2026-11-20で法的期限ではありません。

## GitHub Pages版の構成

GitHub公開の依頼に基づき、独立リポジトリ `takatrp/wage-tax-simulator` とPages配下の `/wage-tax-simulator/` 用に準備しています。既存ポータルは変更しません。Pagesには給与・社名・実CSV・確認済み結果を置きません。examplesは架空データです。

専用照合APIの候補は既存Sites基盤の `wage-tax-rule-check`（`https://wage-tax-rule-check.takatrp0222.chatgpt.site`）です。専用サービスの一般公開はユーザーの明示承認に基づき設定済みです。配備と実環境の確認結果はDEPLOYMENT.mdに記録します。APIが利用できない間は金額表示と印刷を停止します。

`node scripts/build-public.mjs` は承認済みコード・画面指紋が一致する場合だけ `docs/` を生成します。全ESM・CSSを `releases/<実装コード指紋>/` の同じ版へ固定し、既存版の異なる内容への上書きを拒否します。入口HTMLだけが現在版を指します。画面は毎回配信ソースの指紋、APIが返す実装・画面指紋、制度版、機能別レビューと公式本文を照合します。旧入口と新APIの組合せも停止します。

`node scripts/build-worker.mjs [専用フォルダのworker/index.js]` は同じrulesとfreshnessから依存ライブラリなしのWorkerを生成します。公開APIはPagesのOriginのみCORS許可し、空POST以外は拒否します。Origin制限は認証ではなく、第三者がHTTPで呼ぶこと自体は防げません。isolate内の同時実行制限はありますが、全体の呼出上限・費用保証はありません。新規キー・OAuth・課金契約を作らず、既存Sitesの利用枠と運用方針を確認して配備します。新しい認証・課金設定は別途承認が必要です。

## 起動

Windowsでは、このフォルダの「起動.cmd」をダブルクリックします。既存Node.jsで起動し、ブラウザを開きます。起動画面を開いたまま利用し、終了はCtrl+Cまたは画面を閉じます。詳しくは「はじめに.txt」。新規インストール・スタートアップ登録・永続サービス化は行いません。

Node.js 22以上が必要です（検証環境24.16.0）。依存パッケージ、APIキー、OAuthは不要です。

    node server.mjs

ブラウザで http://127.0.0.1:4173 を開きます。Start-Local.ps1も同じ処理です。停止はCtrl+C。HTMLの直接起動では確認APIが使えません。

    npm.cmd test
    node scripts/prepare-review.mjs
    node scripts/capture-sources.mjs

prepare-reviewはテスト結果・コード指紋・架空サンプルを生成します。capture-sourcesは固定公式出典の取得結果と本文指紋をruntime/candidate-snapshot.jsonへ記録します。どちらも本番承認を設定しません。runtimeとmanifestはWeb配信しません。

## 機能と操作

1. 利用開始・画面復帰・再計算時に公式資料を取得します。確認日時、15分の期限、ルール版、対象年度、機能別の担当・承認期限を表示します。
2. 通年実績または着地予測モードを選びます。対象事業年度の開始日で制度を選択します。未確認条件を対象扱いせず、空欄を0円にしません。
3. FX仕訳CSVと文字コードを選び、資料用途・科目区分・期間・集計根拠を確認して反映します。取込後は前案件の資格・認定・教育・繰越・根拠を初期化します。
4. 対象機能の承認と公式照合がそろった枠だけを試算します。未承認・入力未確認の枠は理由のみ表示し、金額を出しません。各枠は比較用で同時合算しません。
5. 端末またはJSONへ入力のみ保存できます。個人明細や確認証明は保存せず、復元で旧結果を破棄し公式情報を再取得します。端末保存は暗号化されません。
6. 印刷には入力・式・判定過程・確認記録・公式出典を含みます。期限切れや入力変更で旧結果と印刷内容を無効化します。

## 着地予測

月初開始・月末終了の12か月事業年度について、年度開始から欠落なくそろった1〜12完了月を扱います。短期・変則年度の法定換算は対象外です。日付または完了月数を指定し、両方指定した場合は一致を検証します。月一覧は任意ですが、指定時は開始位置・連続性・重複を検証します。前期は通年実績が必須です。

賞与を分離できる場合は、当期給与欄へ通常給与の累計を入力します。

    年間給与見込＝通常給与累計÷完了月数×12＋既払い賞与＋予定賞与＋符号付き補正

残月の通常給与を別入力すれば、単純換算の代わりに「累計＋残月見込」を使います。賞与を分離できない場合は、賞与込み累計の単純換算になることを明示確認し、補正の根拠を必須とします。12月完了後の予定賞与や残月給与は0のみです。

継続雇用者給与・通常補塡・助成金・教育費・法人税額は、根拠付きの通年見込を別入力し、自動で倍にしません。継続雇用者の全期間資格は期中に確定できないため、仮定を明示します。既知の条件不充足は仮定で上書きしません。結果と印刷は常に「年間見込・確定判定ではない」と表示し、期間・式・補正・仮定・根拠を残します。予測換算方式自体も独立承認対象です。

## CSV

CSVの入口はFXクラウド仕訳一覧に統一しています。対象年度・完了月・科目区分と根拠を確認して反映し、不足条件は手入力で補完します。詳しくは[FX-CSV.md](FX-CSV.md)を参照してください。提供原本のバイト検証は未実施の試行対応です。

保存JSONの形式は変更せず、既存の入力方法・金額を復元できます。原本や旧結果・公式確認証明は復元しません。

## 実装範囲と計算

対象は法人、両期12か月、組織再編・複雑な通算等なしです。

| 事業年度開始日 | 中小基本率 | 中堅基本率 | 全企業基本率 | 上乗せ |
|---|---|---|---|---|
| 2024-04-01〜2026-03-31 | 全国内1.5%増15%、2.5%増30% | 継続3%増10%、4%増25% | 継続3/4/5/7%増10/15/20/25% | 教育は中小+10%、他+5%。認定+5%（別要件） |
| 2026-04-01〜2027-03-31 | 同上 | 継続4/5/6%増10/15/25% | 廃止 | 教育廃止、認定+5%（別要件） |

古い年度へ現行の中小企業者定義を流用しません。2024-04-01〜2025-03-31開始の中小基本機能は当時の出典を別依存とし、レビューできるまで停止します。2027-04-01以後の延長を仮定しません。90%総額上限の配分、旧雇用促進税制調整、短期・変則年度、特例資格等は初版で停止または専門確認とします。

給与総額P/B、通常補塡R/Rprev、雇用安定助成金S/Sprevに対し、W=P−R、Wprev=B−Rprev、D=W−Wprev、A=(W−S)−(Wprev−Sprev)、控除基礎E=max(0,min(D,A))。全枠の控除基礎は全国内給与、率判定は中小が全国内、中堅・全企業が継続給与です。通常補塡と雇用助成金は分離します。

理論額E×率、当期分優先で調整前法人税額20%まで、残りへ既存中小繰越を充当します。既存繰越は中堅・旧全企業の当期控除と合算できますが、合計20%上限です。前期0や当期給与非増加では利用候補にしません。繰越残高・期限・添付継続は申告明細の確認済み有効残高を入力する限定方式で、自動期限推定はありません。未対応年度では繰越のみの計算もしません。

BigIntで境界を比較し、増加率の表示丸めを判定に使いません。1円未満切捨て概算で、別表各段階の法定端数が承認済みとは表示しません。

## 最新制度確認とレビュー解除

固定URLのみをサーバが取得します。POST /api/checkは本文なしのみ。給与・社名・対象年度・CSV・任意URLはAPIへ送信しません。HostとOriginを独立検証します。外部CDN・解析タグ・外部フォントはありません。

HTML本文（main優先、リンク先を含む）とPDFバイト列をSHA-256照合します。取得成功は法改正反映済みを意味しません。review-manifest.jsonにルール版、コード指紋、機能ごとの出典指紋・担当・レビュー日時・有効期限・開始日期間を保持します。基本計算、教育、認定、繰越、予測方式は別承認です。

必須資料の失敗・差分、未承認、期限切れ、実装差分、年度範囲外は対象機能の計算前に停止。旧金額・印刷も破棄します。無関係な経産省資料の失敗は、適切に独立承認された国税庁資料の基本機能を一律には止めません。画面は対象機能の限定照合であり、法令全体の最新性を保証しません。未取得の新制度告知や別ページの改正、法的解釈の網羅性は定期レビューで担保する必要があります。

解除はREVIEW.mdに沿い、税務仕様・期待値と公式本文を独立確認し、最終コードでテストと出典取得を再実行して、機能ごとにレビュー者が承認する場合のみmanifestを更新します。初回指紋コピーやチェックボックスで自動承認する仕組みはありません。

## 配備候補と未実施事項

既存のDropbox内ツール群と公開ポータルを読み取り確認し、既存ポータル・リポジトリは変更していません。画面は既存の松本会計ツールの青緑色・余白・カード・入力密度に合わせています。

このNode.jsサーバは既存Node.jsホスティングへ独立配置できます。ローカル待受は127.0.0.1のみ。公開時は許可Host/Origin、HTTPS、認証、レート制限、監視、公式取得成功を実環境で検証する必要があります。Sites向けの照合専用Workerを、同じrulesとfreshnessから生成します。GitHub Pages等の静的ホスティング単体では毎回の公式確認を実現できません。

GitHub Pagesと専用Sites APIの公開は明示承認に基づき進めています。配備結果はDEPLOYMENT.mdを参照してください。既存ポータルは変更せず、新規APIキー・OAuth・課金契約は作成していません。継続運用では利用枠とレビュー更新担当の確認が必要です。

公式根拠はアプリの出典一覧およびpublic/rules.mjs、独立指摘への対応はCHANGELOG-REVIEW.md、テストはoutput/test-report.txtを参照してください。本版は限定した計画用の動作実装で、申告利用可能との完成宣言ではありません。
